# STUDYVERSE

**Turn your notes into worlds worth exploring.**

Playable AI-powered educational game generator. Paste or upload your course notes and explore a 3D Voxel Quest world where you learn by doing (e.g., interactive Newton's Second Law: adjust force and mass to unlock gates).

## Features
- Dark neon gaming UI
- First-person Voxel Quest (WASD + mouse)
- Interactive \( F = ma \) physics challenge
- PDF/TXT upload + paste notes
- Local progress tracking
- Sample demos for Physics, Calculus, Biology

## Run locally
```bash
npm install
npm run dev
```
